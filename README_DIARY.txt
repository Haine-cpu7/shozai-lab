【☀️ はてな日和：DIARY追加パッチ】

このZIPの中身
- index.html … 玄関のDIARYリンクを自分のサイトのdiary.htmlへ変更。古い「DIARYはnote」の説明を削除
- diary.html … 日付と本文だけを表示する日記ページ
- diary.txt … 日記本文を保存するテキストファイル（最初は空です）

■ はじめに
上記3ファイルをGitHubの「Haine-cpu7/shozai-lab」の一番上の階層にアップロード。
index.htmlだけは既存ファイルを上書き。ほか2つは新規追加。

■ 日記の書き方
GitHubで diary.txt を開き、えんぴつマーク（Edit this file）を押して、日付と本文を書いて保存（Commit changes）するだけです。
記事タイトル、ハッシュタグ、装飾、タグ付け不要。文字と改行だけでOK。

書き方の例（以下は架空の例。diary.txtの初期ファイルには入れていません）

2026-10-12
今日ちょっと涼しいｗ
お昼のカレーおいしかった。

---

2026-10-11
昨日は眠かった。


複数の日記の間は、半角の --- だけの行を置いてください。
日付は YYYY-MM-DD（例: 2026-10-12）で書きます。
日記は日付の新しい順に表示されます。

■ 注意
GitHub Pages は静的サイトです。公開されたDIARYページ内に投稿欄はありません。
GitHubで diary.txt を編集・保存すると、サイトが再公開された後で反映されます。
ブラウザで開いて直接書き込んでも、GitHub側への自動保存はされません。
日記はインターネットに公開されるので、公開してよいことだけ書いてください。
