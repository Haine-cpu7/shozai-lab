どの社会が、
いちばん幸せなのか？

ごりっごりの資本主義・社会主義・共産主義。同じ100人を3世界へコピーして30年間住ませます。能力も性格も家庭事情も運も同じ。違うのは制度だけ。

IMPORTANT

これは実在国家の再現ではありません

極端化した仮想モデル

3つの名前は制度ラベルとして使います。特定の国・政党・歴史体制を評価するゲームではありません。政治的自由、戦争、腐敗、移民、環境などはモデル化していません。共産主義モデルの「自由」は経済的な職業・消費・私的資本選択だけを指します。

THREE FICTIONAL SOCIETIES

この実験でいう3つの社会

ここでの説明は、現実の国そのものではなく、制度の違いをわざと強くしたゲーム内モデルです。まずは「何が違う社会なのか」を超ざっくり把握してから回してください。

💰 ごりごり資本主義

一言でいうと：
稼ぐ・投資する・増やす自由が大きい社会。

頑張った人や運が良かった人は大きく伸びやすい一方、再分配と公的保障は弱め。失業や不調に当たったときの落差も大きくなりやすい。

このモデルでは
私有資本：大 / 報酬差：大 / 再分配：少 / 経済的選択：大 / 保障：少
⚠️ 弱点・デメリット
格差が広がりやすく、失業や不調を引いた人の下振れが大きい。少数の大成功者が平均を押し上げても、真ん中や下の人まで豊かとは限らない。
上振れ大下振れ大私有資本 大
🏥 ごりごり社会主義

一言でいうと：
稼ぐ自由も残しつつ、みんなで支え合う比重を大きくした社会。

私有財産や投資は残るけれど、所得の一部を広く集めて再分配と公共サービスに回す。大きな格差を抑えながら、ある程度の上振れも残す中間型。

このモデルでは
私有資本：中 / 報酬差：中 / 再分配：多 / 公共サービス：厚い / 保障：多
⚠️ 弱点・デメリット
再分配を厚くするほど、頑張ったときの報酬差や私的に資本を増やす余地は小さくなる。公共サービスの効率が悪いと、「たくさん集めたのに十分な価値を返せない」状態にもなり得る。
格差圧縮私有財産あり保障 大
🚩 ごりごり共産主義

一言でいうと：
個人で大きく増やすより、みんなの生活をそろえることを強くした社会。

生産資本の共同所有を強くし、所得差と私的な資本蓄積をかなり圧縮。基本生活の保障は厚いが、個人が資本を使って大きく増やす余地は小さい。

このモデルでは
私有資本：小 / 報酬差：小 / 共同供給：大 / 基本保障：最大 / 経済的選択：小
⚠️ 弱点・デメリット
私的な資本蓄積・起業・報酬差を強く抑えるため、「もっと働く・工夫する・リスクを取る」経済的な動機が弱くなりやすい。中央で配分を決める比重が大きいほど、需要の読み違い・不足・非効率が起きたときに修正しにくい。
格差圧縮 大共同所有保障 最大

注意：ここに書いた弱点は主に経済制度のトレードオフです。特に「共産主義」について、歴史上の一党支配・政治的自由・言論の自由などへの評価はこのゲームでは扱っていません。逆に、現実の資本主義・社会主義も国ごとに制度が大きく違います。3つとも現実の国をそのまま再現したものではありません。

SOLVE DIFFERENT PROBLEMS

そもそも3制度は何を解決しようとしているの？

ここが大事です。3制度は「同じ問題への別回答」ではなく、出発点の悩み自体が少し違います。 だから、このゲームで共産主義がいつも1位を取らなくても、「存在意義がない」とはなりません。

💰 資本主義が解決したいこと
「人に自由に競争・投資・商売をさせた方が、全体として富が増えやすいのでは？」という問題意識です。
重視するもの
成長 / 起業 / 投資 / 上振れ / 個人の自由
この実験で見えやすいこと
真ん中や上位の資産が伸びやすい反面、下振れや格差も大きくなりやすい。
🏥 社会主義が解決したいこと
「市場は使いたい。でも、放っておくと格差や生活不安が大きすぎるのでは？」という問題意識です。
重視するもの
再分配 / 公共サービス / 安定 / 中間層 / 生活保障
この実験で見えやすいこと
資本主義ほどの上振れは弱くても、真ん中や下の人を守りやすく、総合指標で強く出やすい。
🚩 共産主義が解決したいこと
「そもそも格差や搾取を生む私有資本の構造自体をなくした方がいいのでは？」という問題意識です。
重視するもの
格差の最小化 / 共同所有 / 基本保障 / 階級差の圧縮
この実験で見えやすいこと
格差を抑える力は強いが、個人が資本を使って大きく増やす余地も削るため、「資産」や「上振れ」系指標では勝ちにくい。
超ざっくり言うと
資本主義は「増やす」寄り、社会主義は「守りながら増やす」寄り、共産主義は「そもそも大きな差を作らせない」寄りです。どれが1位かより、何を最優先にする思想なのかを見ると、結果の意味が分かりやすくなります。
HAPPINESS IS NOT ONE THING

「幸福」の定義を選ぶ

順位が変わるか？

幸福度は「物質的余裕・安心・経済的選択・余暇・健康」の合成スコア。正解の幸福を決めるものではありません。BOT本人の好みも28%混ぜています。

INCENTIVE RULE

報酬差が小さくても「頑張るほど損」にはしない

報酬差で努力が変わる設定を強くすると、報酬差が大きい制度ほど意欲の高いBOTへの追加リターンが大きくなります。報酬差が小さい制度では追加リターンが小さいだけで、努力そのものがマイナス報酬に反転することはありません。

SURVIVAL HYPOTHESIS

この社会で、どう生きるのが賢そう？

30年の結果から立てる事後仮説

ここは「正解」を出す場所ではありません。この100人・このSeedの30年結果から、どんな条件の人がうまくいったかを観察し、次に検証する仮説を作ります。現在のBOTは職業・投資・労働時間などを自分で選び直すモデルではないため、ここで言えるのは「賢い選択の候補」までです。

次に本当に検証したいこと
貯蓄率、技能への投資、働く時間、リスクの取り方、公共サービスの利用などをBOT自身が選べるようにして、同じ人・同じ運・同じSeedのまま「戦略だけ」を変える。そこで初めて「この制度では、どの生き方が賢いのか」を一段深く検証できます。

※相関は因果関係ではありません。ここで表示する係数は、この1世界線の100人について「その条件と30年後の結果がどれくらい一緒に動いたか」を見る探索用の値です。

HUMAN BEHAVIOR HYPOTHESIS

なぜ、人は「働かない人」「努力が少なく見える人」を嫌うことがある？

仮説 / 未検証
まず分ける：
その人の分まで本当に自分が負担しているなら、不公平感には実際の利害があります。ここで考えたいのは、自分に直接の損がほぼなくても、嫌味・非難・嫉妬・「もっと苦労しろ」が出るのはなぜか、という部分です。
この実験との接続
社会制度は「誰が貢献し、誰が受け取るべきか」のルールそのものです。働かない人への反感は、単純な嫉妬だけでなく、ただ乗りを防いで協力を維持しようとする規範反応として生じる可能性があります。
仮説A　「ただ乗り」を監視する脳
人間は協力集団で暮らしてきたため、「利益を受け取るなら貢献もしてほしい」という規範に敏感なのかもしれません。実験研究では、非協力者を自分が損してでも罰する行動が観察されています。問題は、本当はただ乗りしていない人まで誤認して罰する可能性があることです。
仮説B　自分の苦労を無駄にしたくない
人は大きな努力を払ったものほど、その対象や成果を高く評価しやすい「努力正当化」の傾向があります。自分が長時間働いたあとで、他人が少ない努力で同じ場所へ着くと、自分の犠牲の意味が揺れるため、相手を「楽している」と価値下げする可能性があります。
仮説C　「努力した人が報われるべき」という物語
努力・能力・責任で結果が決まるというメリトクラシー観は分かりやすい世界説明です。そこから外れる人が現れると、「不公平」「ずるい」と感じやすくなるかもしれません。逆に、失敗者を「努力不足」と内部要因だけで説明しやすくなる可能性もあります。
仮説D　上方比較と「ふさわしくない成功」
自分より楽そうなのに、同じか上の生活をしている人は比較対象になります。研究では、相手の優位を「本人にふさわしくない」と感じるほど、建設的な羨望よりも、相手を下げたい悪意ある嫉妬に結びつきやすいことが示されています。
仮説E　見えない貢献はゼロ扱いされやすい
給料・出勤・残業は見えやすい一方、家事、育児、介護、過去の貯蓄、リスクを取った時期、仕組み化、資産管理は外から見えにくい。観察者が見える情報だけで判断すると、「働いていない＝何もしていない」という誤分類が起きます。
仮説F　嫌味は「規範を守らせる信号」でもある
「普通は働くでしょ」「そんな楽してていいの？」という言葉は、個人感情だけでなく、周囲に「この行動は認めない」と知らせる社会的制裁として機能する可能性があります。協力維持には役立つ一方、古い規範が環境変化後も残ると、不要な攻撃にもなります。
このサイトでの暫定仮説
「働かない人が嫌われる」「努力薄型が嫌味を受ける」を嫉妬だけで説明しない。①実際の負担移転、②協力規範、③努力正当化、④メリトクラシー、⑤社会比較、⑥見えない貢献の誤認が重なった結果ではないか、と置きます。今後はこの仮説自体もBOTで検証対象にします。
研究上の手掛かり： 公共財ゲームでは非協力者への costly punishment が観察され、協力維持との関係が報告されています。仕事規範が強い社会ほど失業者へのスティグマが強いという研究、努力が成果の価値を高める「effort justification」、成功の deservingness が悪意ある嫉妬と関係する研究もあります。これらは今回の個別ケースの原因を証明するものではなく、仮説を作るための外部知見です。

🧒 小学生でもわかる解説

何をくらべてるの？
同じBOTを、資本主義・社会主義・共産主義という違うルールの社会に住ませます。
超かんたんに言うと：
社会のルールを変えると、「お金が増えやすい」「下の人が苦しくなりにくい」「格差が小さい」など、得意なことが変わります。全部で1位の社会があるとは限りません。
