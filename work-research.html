EXPERIMENT No.07 / RESEARCH MODE

なぜ働くの？
働くとは？

「働くべき」という価値判断を先に置かず、まず 就業・無給の仕事・資産・家計移転・自由時間を分離します。その上で、何がないと生活が回らないのかを固定Seedで比較します。

DEFINITION BEFORE OPINION

「無職＝何も働いていない」は統計上も雑

ILO：work と employment は別
ILOは work を、他者または自家使用のために財・サービスを生み出す活動と定義し、その一形態として賃金・利潤を目的とする employment を区別しています。
ILO: Work and employment are not synonyms
家事・育児・介護も own-use work
料理、掃除、住居の維持、育児、家族の介護などは、自家使用のためのサービス生産として ILO の work 枠組みに含まれます。
ILO: Own-use production work

このページでは「給料をもらう仕事」を就業、「家事・ケアなどの無給生産」を無給の仕事と呼び分けます。学習や休息は別枠です。

EVIDENCE TYPE

「支持」の意味を3種類に分ける

設計挙動
式やルールに方向を直接入れているもの。支持されても「新発見」ではなく、主に内部整合性の確認です。
創発比較
複数の仕組みを組み合わせた結果として出る比較。モデル内では一番「実験」に近い部分です。
外部データ・定義
公的統計・研究・国際定義など外部ソースに基づく部分。モデル結果とは分けて扱います。

重要：「モデル内で支持」は、現実世界で証明されたという意味ではありません。特に「設計挙動」は、想定した式が想定どおり働いたかを見るチェックです。

HYPOTHESES

先に仮説を置く

H1設計挙動
資産も共同家計もないなら、就業ゼロは生活赤字を増やす。
H2設計挙動
共同家計が基礎生活費をカバーするなら、本人の就業は必須ではなくなる。
H3設計挙動
家事・ケアは外注費を減らせても、現金収入そのものにはならない。
H4設計挙動
資産が厚いほど就業を減らせるが、市場の下振れに依存する。
H5創発比較
純資産最大と自由時間最大の生き方は一致しない。
H6外部データ・定義
就業ゼロでも家事・ケアが多ければ、「働いていない」とは言えない。
RUN

固定Seedで検証

v1.40：共同家計収入と開始資産を別々に操作します。H2は「共同家計だけ」、H4は「資産だけ」を変えるため、以前の交絡を除去しました。家事の外注換算1,500円/hは価値表示、ここで選ぶ300〜1,200円/hは「家計支出を実際に減らす」と仮定する別パラメータです。

WHAT THIS MEANS

この実験の最終問い

「働かなければならない」のではなく、「生活に必要な資源をどこから得るか」を決めなければならないのでは？
給料、資産、共同家計、自家生産。入口が違えば、本人に必要な就業時間も変わります。一方で、就業しなくても家事・ケアという work は残り得ます。
LIMITS

まだ実装していないもの

社会保険、年金、実際の税制、職場の人間関係、仕事から得る意味や地位、孤独、病気、子どもの事情、離婚・死別、家計内の公平性などは未実装です。したがって、このモデルから「人は働くべき」「働かなくていい」という道徳的結論は出せません。

EASY MODE / FOR EVERYONE

🧒 小学生でもわかる解説

何をくらべてるの？
本人が働く時間、家事・ケア、共同家計の収入、持っている資産を変えて30年を比べます。
超かんたんに言うと：
生活に必要なお金を手に入れる方法は「本人が長時間働く」だけではありません。家計収入や資産があれば、必要な有償労働の量は変わります。家事や自由時間も消えているわけではありません。

ここだけ注意： 「働かなくていい」が正解という実験ではありません。どの資源を使って生活を支えているかを分けて見ます。

難しい数字や研究用語が分からなくても、まずここだけ読めば「この実験で何を見ているか」が分かるようにしています。
