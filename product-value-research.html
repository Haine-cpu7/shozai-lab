QUESTION

問い

情報そのものが生む直接的な金銭成果が販売価格を下回っていても、実用周辺価値や購入前期待があれば、売り手の商売は黒字化するか？ そのとき買い手側の価値はどうなるか？
OPERATIONAL DEFINITION

「成立」を1個の言葉にしない

売り手成立
24か月累計の売り手損益が0円超。
買い手の直接金銭ROI
情報そのものの直接金銭価値 − 販売価格。
買い手の総価値差
直接金銭価値＋実用周辺価値 − 販売価格。訴求だけの価値は購入後の受取価値へ加えない。

MODEL ASSUMPTIONS

モデルに置いた仮定

A1
直接金銭価値と、時短・実行補助などの実用周辺価値は別に計算する。
A2
権威・口コミ・変身訴求は購入前期待を上げうるが、購入後の直接成果には自動加算しない。
A3
期待と受取価値が離れるほど返金・評判低下が起こりやすい。
A4
売り手には初期制作費・獲得費・販売ごとの提供コストがある。
A5
毎月新規見込み客が入る。評判は購入確率へ一部反映される。
A6
円換算された実用価値は人間の実測値ではなく、比較のための玩具係数。
A7
購入は「欲しい度」「支払意思額（WTP）」「この購入に回せる可処分予算」の3ゲートをすべて通った時だけ成立する。
A8
可処分予算は全タイプ共通の750〜25,000円の玩具分布。価値観と支払能力を混同しない。

項目種類扱い
4商品の付加価値係数設計由来人間データから推定した価格ではなく、比較のための玩具係数。
購入率・返金率・評判モデル内結果設定した係数・WTP・可処分予算とSeedから出た値。現実の市場率ではない。
可処分予算 / WTP設計由来＋モデル内状態予算分布は玩具設定。WTPは知覚価値と価格感応度から計算し、「欲しいけど高すぎる / 欲しいけど払えない」を分離する。
売り手損益モデル内結果価格・購入数・返金・制作費・獲得費・提供コストを差し引いた値。
No.01の実在教材関連実験No.21の2,500円へ自動転記していない。別実験として参照する。
MODEL BOUNDARY

この結果から言ってはいけないこと

売り手が黒字だから商品が良い、買い手の直接金銭ROIがマイナスだから商品に価値がない、というどちらの短絡もこのモデルは採用しません。

実用周辺価値の円換算、返金、評判、獲得コストはすべて玩具モデルの前提です。現実の情報商材市場の利益率や購入者満足を推定するものではありません。

EASY MODE / FOR EVERYONE

🧒 小学生でもわかる解説

何をくらべてるの？
商品の直接金銭価値、便利さ、宣伝、買い手のWTP・予算、売り手の利益を別々に計算します。
超かんたんに言うと：
お店がもうかることと、お客さんが得することは別です。中身の直接金銭価値が値段より小さくても、便利さなどで売れて黒字になることがあります。でも「売れた＝買った人も得した」とは限りません。

ここだけ注意： 売り手が黒字だから良い商品、買い手の直接ROIがマイナスだから無価値、と単純には決めません。総価値と売り手利益を別に見ます。

難しい数字や研究用語が分からなくても、まずここだけ読めば「この実験で何を見ているか」が分かるようにしています。
