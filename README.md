# 商材実験室

情報商材に書かれた「成功法則」を全ページから抽出し、BOTの行動ルールへ変換して長期シミュレーションするミニゲーム集です。

## 収録

### Experiment No.001
**1万円相当の情報は、本当に1万円を生むのか？**

- 観測期間: 720日
- 商材BOT / 人脈BOT / 日記BOT / バズBOT / 記事BOT
- Twitter教材101ページ＋ライティング教材47ページ、計148ページを全ページ確認
- 本文の運用手順・数値例・成功事例・判断基準を抽出し、シミュレーション可能な要素を行動ルール・確率変数へ変換
- 100世界線比較
- 最終日に観測データから仮説を自動生成

## 5つのBOT

- 商材BOT: 教材どおりのSNS運用 + 教材ライティング施策
- 人脈BOT: 商材BOTと同条件 + 60人規模の情報商材コミュニティの相互応援
- 日記BOT: 戦略なしSNS + 一般記事（教材最適化なし）
- バズBOT: バズ重視SNS + 一般記事（教材最適化なし）
- 記事BOT: SNS最小限 + 一般記事へ作業を集中

## v1.3 3つの探索モード

### ① 現実運用モード
各BOTが本来の戦略どおりに動きます。

- 商材 / 人脈 / 日記 / バズ: 5日に1記事
- 記事BOT: 毎日1記事
- 記事量の差も含めて「最終的に誰が一番稼ぐか」を比較

### ② 同記事数モード
全BOTを720日で144記事に固定します。

- 記事量の差を除外
- SNS戦略、記事品質補正、人脈の差を比較
- 探索ページでは教材由来の品質・転換補正をゲーム仮定として含むため、因果検証ではありません

### ③ 同作業時間モード
全BOTに同じ1,000時間を配ります。

- 各BOTの平均作業量から活動頻度を調整し、表示上1,000時間へ正規化する探索モード
- 各BOTの基本戦略に応じて、SNS / 記事 / 人脈へ時間を配分
- 厳密な実時間上限の比較は `hypothesis.html` の仮説検証室で行います

## v1.4 「教材とは？」結果分析

720日終了後の結果画面に、大見出し **「教材とは？」** を追加。

商材BOTと教材なし比較群（日記BOT）の差を直接表示します。

- 売上差
- PV差
- 1記事あたり売上差
- 1時間あたり売上差
- フォロワー差
- 作業時間差

その数字から、「売上と効率の両方に効いた可能性」「売上は増えたが時間効率は改善しなかった可能性」「この世界線では追加価値を確認できなかった可能性」など、結果に応じた仮説を自動生成します。

教材の価値を断定する機能ではなく、選択した実験モードと1世界線の観測結果から仮説を出すための表示です。


## v1.5 仮説検証室

`hypothesis.html` を追加。探索ページとは別に、**事前仮説 → 条件固定 → 100世界線 → 支持 / 支持されず / 判定困難** の順で検証します。

事前仮説：

- H1: 教材を実践すれば2年で教材代1万円を回収できる
- H2: 教材には教材なし運用より追加の経済価値がある
- H3: 同じ1,000時間なら教材運用の方が効率よく利益を残せる
- H4: 人脈は同じ教材運用の成果を増幅する
- H5: 教材より単純な記事量の方が総利益では強い可能性がある

検証ページでは標準状態で、教材BOTに自動の「高品質」バフを与えません。記事の当たり分布、CTR、CVR、フォロー転換の基礎値は教材あり・なしで共通です。違いは投稿頻度、リンク運用、記事本数、人脈、作業時間、教材代など、明示された行動条件です。

教材のライティング施策が実際には記事流入を改善すると仮定したい場合だけ、0% / +10% / +25% / +50% の感度分析で明示的に切り替えられます。

同作業時間の検証では作業時間を実際に積み上げ、1,000時間を超える新規作業を行わない方式に変更しています。

## GitHub Pages 公開手順

1. ZIPを展開
2. 中の `index.html` / `hypothesis.html` / `README.md` / `.nojekyll` をGitHubリポジトリ直下へアップロード
3. GitHubの **Settings** → **Pages**
4. **Build and deployment** → **Deploy from a branch**
5. `main` / `(root)` を選択して保存
6. 数分後に公開URLが発行されます

ビルド不要の静的サイトです。

## 実験室の原則

- 商材を最初から詐欺扱いしない
- 成功を保証もしない
- 教材の施策をBOT化する
- 現実寄りの確率・競争・時間コストを加える
- 複数世界線で観察する
- 最後に「断定ではなく仮説」として結果をまとめる

## 注意

シミュレーションは未来予測ではありません。一部の数値は公開ベンチマークを参考にしたゲーム用仮定です。

## 教材のモデル化について

教材本文148ページをそのままBOTへ読み込ませ続けているわけではありません。全ページを確認し、シミュレーションに使える内容を抽出して、投稿頻度・フォロワー成長・バズ確率・リンク遷移・記事品質・検索流入・成果報酬・作業時間などの変数や行動ルールへ変換しています。

スクリーンショット内の全ツイート文面や紹介リンクまで、一語一句すべてを変数化しているわけではありません。
