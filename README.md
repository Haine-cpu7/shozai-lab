# 商材実験室

実在する情報商材・教材を全ページ確認し、運用ルールをBOT化して長期シミュレーションするミニゲーム集。

## ページ構成

### 1ページ目 `index.html` — ゲーム

「情報商材をAIに読ませてBOTで回してみたw」という遊び側。

- 720日
- 5BOT
- 現実運用 / 同記事数 / 同作業時間の3モード
- 1世界線の探索
- 「教材とは？」の事後仮説

ここでは教材の主張をゲーム内の補正へ変換した探索モデルも含むため、因果効果の証明には使わない。

### 2ページ目 `hypothesis.html` — ガチ研究

事前仮説 → 条件固定 → 出典確認 → 100世界線 → 区間推定 → 感度分析 → 頑健性チェックを行う。

#### v1.6 の強化点

- H1〜H5を結果を見る前に固定
- 教材の自動品質バフは標準0%
- 乱数Seedを固定し、同条件を再現可能
- BOT比較では同じSeedを使い、可能な範囲で同じ乱数世界線を比較
- 100世界線の勝率だけでなく95% Wilson区間を表示
- 旧60/40ルールではなく、95%区間が50%を跨ぐかで「支持 / 支持されず / 判定困難」を決める
- 変数を `外部ベンチマーク / ゲーム仮定 / 教材由来 / 混合` に分類
- 悲観 / 標準 / 楽観の3外部環境を追加
- 教材効果 0 / +10 / +25 / +50% は別軸の感度分析
- 3環境を各100世界線で一括実行する「頑健性チェック」を追加
- 同作業時間は表示上の正規化ではなく、実作業を積算して1,000時間で新規作業を停止
- 研究ページのSEO流入は720日時点の総量比較に必要なため、登録→成熟→減衰曲線を積分して累積PV化し、高速にMonte Carloを回す

## 主な外部根拠

- Google Search Central: クロールには数日〜数週間かかる場合があり、クロール・インデックス時期は保証されない
- Ahrefs 2025: 新規ページが1年以内にTop10へ入る割合は、ランダムURL全体で1.74%、非空英語コンテンツ抽出で6.11%
- Shopify / impact.com: 購入型アフィリエイトCVRは1〜3%程度という目安
- Shopify 2026: アフィリエイトリンクCTRのベースライン0.5%、1%超は非常に良好という目安
- Rival IQ: X/Twitterのブランド投稿エンゲージメント参考値。ただし本モデルのバズ率・フォロー転換率と同じ指標ではないため直接校正しない

外部データは日本の個人ブログ専用ではないため「正解値」として使わず、ゲーム仮定の境界情報として使う。

## 重要な限界

これは現実世界のRCTでも未来予測でもない。100世界線は実在100人のデータではなく、設定した確率モデルのMonte Carlo反復。

研究ページの目的は「教材が本当に効く」と断定することではなく、**どの結論が、どの仮定に依存しているかを見える化すること**。

### No.002 の問い

### No.002 で使う主な外部境界情報

- メルカリ公式：販売手数料10%
