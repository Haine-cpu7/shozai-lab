# 商材実験室

情報商材に書かれた「成功法則」を全ページから抽出し、BOTの行動ルールへ変換して長期シミュレーションするミニゲーム集です。

## 収録

### Experiment No.001
**1万円相当の情報は、本当に1万円を生むのか？**

- 観測期間: 720日
- 商材BOT / 人脈BOT / 日記BOT / バズBOT / 記事BOT
- 商材BOT: 毎日X運用 + 5日に1記事
- 記事BOT: 毎日1記事
- 人脈BOT: 商材BOTと同条件 + 情報商材コミュニティの相互応援
- 100世界線比較
- 最終日に観測データから仮説を自動生成
- Twitter教材101ページ＋ライティング教材47ページ、計148ページを全ページ確認
- 本文の運用手順・数値例・成功事例・判断基準を抽出し、シミュレーション可能な要素を行動ルール・確率変数へ変換

## GitHub Pages 公開手順

1. ZIPを展開
2. 中の `index.html` / `README.md` / `.nojekyll` をGitHubリポジトリ直下へアップロード
3. GitHubの **Settings** → **Pages**
4. **Build and deployment** → **Deploy from a branch**
5. `main` / `(root)` を選択して保存
6. 数分後に公開URLが発行されます

ビルド不要の静的サイトです。

## 実験室の原則

- 商材を最初から詐欺扱いしない
- 成功を保証もしない
- 教材の施策をBOT化する
- 現実寄りの確率・競争・時間コストを加える
- 複数世界線で観察する
- 最後に「断定ではなく仮説」として結果をまとめる

## 注意

シミュレーションは未来予測ではありません。一部の数値は公開ベンチマークを参考にしたゲーム用仮定です。

## 教材のモデル化について

教材本文148ページをそのままBOTへ読み込ませ続けているわけではありません。全ページを確認し、シミュレーションに使える内容を抽出して、投稿頻度・フォロワー成長・バズ確率・リンク遷移・記事品質・検索流入・成果報酬・作業時間などの変数や行動ルールへ変換しています。

スクリーンショット内の全ツイート文面や紹介リンクまで、一語一句すべてを変数化しているわけではありません。
